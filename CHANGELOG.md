# Changelog

## 0.2.0 - 2026-09-17

### Added
- Automatic post-build BuildReport snapshot with packed asset size contribution.
- Diagnostics for Always Included Shaders, shader keyword pressure, and ShaderVariantCollection size.
- TMP Font Asset diagnostics without requiring a compile-time TextMeshPro dependency.
- Sprite Atlas diagnostics for packer mode, Read/Write, mipmaps, WebGL size, inclusion, and empty atlases.
- Low-risk fix registry with per-issue fixes and a bulk fix button.
- Low-risk fixes for null Always Included Shader entries and WebGL debug symbols.

### Changed
- Expanded the editor window summary with fixable issue counts.
- Updated package metadata and documentation for V0.2.

## 0.1.0 - 2026-09-16

### Added
- Initial Unity Package Manager package structure.
- MiniGame Doctor UI Toolkit editor window.
- Diagnostics for Resources, large assets, textures, audio, build scenes, WebGL settings, and WeChat mini-game SDK readiness.
- Severity sorting and asset ping/selection from diagnostic results.
